VIS by STYL — premium landing page

Open index.html in any modern browser. Keep the assets folder alongside it.
No build, dependencies, external fonts, tracking, or network connection required.
Contact buttons open the original email, phone and website links.
The standalone VIS-preview.html supplied alongside the ZIP embeds all page assets.

Design: responsive charcoal / warm ivory / lime visual system, clear section hierarchy,
mobile navigation, keyboard focus styles, skip link, descriptive alternative text,
reduced-motion support, and responsive WebP with JPEG fallback.

Imagery: hero-original.png is the 1536 × 1024 AI-generated master, produced using
the built-in image generation tool. JPEG and 1536 / 960 WebP derivatives are included.
Solution SVG illustrations are scalable. The STYL logo uses the user-supplied PNG.
The twilight hero includes callouts identifying payment, management and inventory. Mobile layouts use numbered markers and a caption key. Lifestyle imagery is conceptual; the operations panel is an HTML illustration,
clearly labelled as illustrative, rather than an actual product screenshot.

Validation: local asset references, section anchors and original contact destinations
checked. Browser layout testing was attempted but unavailable because the environment
blocked browser launch and the local preview server. Responsive rendering and keyboard
interaction still require a final check in a browser before production publication.

Expanded product content: membership controls, staff points wallet, campaign codes, operator app, protocols and rollout FAQ. See POSITIONING-NOTES.md for source mapping and competitive claim limits. All enquiry CTAs link to https://styl.com.sg/contact-us/.
